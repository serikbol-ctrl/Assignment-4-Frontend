## Project overview
This project demonstrates basic HTML forms, built-in HTML5 validation, Bootstrap form styling, Bootstrap validation feedback, and a responsive registration form.

## Requirements
- A modern web browser
- Internet connection to load Bootstrap 5.3 from its CDN

## How to run
1. Download or clone this repository.
2. Open `index.html` in a browser.
3. Select a task from the home page.

## Task 0 — Simple Contact Form
Created a contact form with Name, Email, Message, and Submit fields. Every input has a corresponding label.

## Task 1 — Form with HTML5 Validation
Added `required`, `type="email"`, `minlength`, and `maxlength` attributes. The browser displays built-in messages when required values are missing or invalid.

## Task 3 — Bootstrap Validation Styles
Used JavaScript with Bootstrap `is-valid` and `is-invalid` classes. Feedback messages appear below fields, and a summary message appears after submission.

## Task 4 — Registration Form
Created a responsive registration form with first name, last name, email, password, confirm password, gender radio buttons, hobbies checkboxes, country dropdown, Submit, and Reset buttons. The form checks required values, email format, minimum password length, and whether both passwords match.

**Screenshot:** ![task4](<Снимок экрана 2026-10-16 195557.png>)

## Summary
During this assignment, I practiced creating accessible HTML forms, using HTML5 validation attributes, styling forms with Bootstrap, arranging inputs with the Bootstrap grid system, and displaying validation feedback with JavaScript. I tested the forms with both valid and invalid data.
